## 2. 脚本能力

### `scripts/backup.sh`

- 在 MySQL 健康后执行一致性逻辑备份，任一等待、导出、压缩、附件归档或校验失败非零退出。
- 生成数据库备份、附件归档、SHA-256、manifest、Flyway 版本和行数/对象计数快照。
- 不记录或打印数据库密码。

### `scripts/restore.sh`

- 恢复前必须同时校验 manifest 和备份 SHA-256，不信任单独文件名。
- 默认拒绝非空目标；仅显式授权才能进入覆盖路径。
- 目标项目必须使用恢复专用前缀，环境文件内项目名必须完全匹配，MySQL/附件卷必须以该目标项目精确命名；生产项目名和卷无法通过预检。
- MySQL 未健康、等待超时、导入失败、校验失败或表/角色/用户/Flyway 数量不一致时立即非零退出，不输出“恢复完成”。
- 恢复运行在独立 Compose 项目和独立数据卷，不复用源库数据卷。
