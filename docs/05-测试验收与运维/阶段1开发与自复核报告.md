## 5. 安全和边界复核

- 数据范围由后端强制，`READONLY` 写操作统一 403，无策略默认拒绝，跨组织 ID 不能穿透列表/详情/写入。
- 附件、导入导出、批任务、审计、Inbox/Outbox 与接口重试不能绕过数据范围和精确操作权限。
- `.env` 被 Git 忽略且不属于提交候选；扫描器只读取 Git 已跟踪或未忽略的候选文件，不读取本地忽略秘密。
- 未运行本地 Docker 构建、容器、真实 MySQL、备份或恢复；不把 Compose 解析、H2 或脚本语法冒充真实环境验收。

## 7. npm 漏洞处置结论

- 两个 high 为 `brace-expansion`（ESLint、OpenAPI TypeScript、typescript-eslint、vue-tsc 链）和 `fast-uri`（openapi-diff/json-schema-diff/Ajv 链），均为间接开发/校验依赖，不进入 Nginx 静态运行镜像。
- 原 moderate `postcss` 由 Vue SFC/Vite 构建链引入；即使 npm 的 omit 分类受 peer/生产标记影响，服务器运行物仅为构建后的静态文件，不执行 Node/PostCSS。
- 处置只更新锁文件中的兼容补丁版本：`brace-expansion` 1.1.18/2.1.4/5.0.9、`fast-uri` 3.1.5、`postcss` 8.5.25；`package.json` 和直接依赖版本未变。完整及生产依赖审计均已真实返回 0 漏洞，因此不延期。
