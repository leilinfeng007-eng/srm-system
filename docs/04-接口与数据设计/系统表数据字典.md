# 阶段0系统表数据字典

阶段0只包含以下 10 张平台表。结构权威为 `backend/src/main/resources/db/migration/V1__create_system_baseline.sql`；本文用于交接，不替代迁移。

| 表 | 主键/关键约束 | 用途 | 敏感性与保留规则 |
|---|---|---|---|
| `sys_user` | `id`；`username` 唯一 | 内部账号、强哈希密码、状态、显示名、最后登录 | 不存明文密码；账号停用优先于删除 |
| `sys_role` | `id`；`role_code` 唯一 | 角色定义 | 稳定 code 参与授权，不依赖自增 ID |
| `sys_user_role` | `(user_id, role_id)` 唯一 | 用户与角色多对多 | 通过外键保持引用完整性 |
| `sys_menu` | `menu_code`、`route` 唯一 | 目录/页面、组件键、顺序、阶段、可见性 | 菜单源于模块清单；隐藏预留不下发 |
| `sys_permission` | `permission_code` 唯一 | `domain:resource:action` 权限定义 | 禁用权限不进入用户 authority |
| `sys_role_permission` | `(role_id, permission_id)` 唯一 | 角色接口/动作授权 | 后端鉴权的数据库依据 |
| `sys_role_menu` | `(role_id, menu_id)` 唯一 | 角色菜单可见性 | 只影响导航可见性，不替代接口鉴权 |
| `sys_refresh_token` | `token_hash` 唯一；活动会话索引 | 刷新令牌摘要、访问 JTI、撤销与过期 | 只存 SHA-256 摘要；退出/旋转后撤销 |
| `sys_login_log` | 用户与时间索引 | 登录成功/失败、原因、IP 摘要、traceId | 不记录密码、令牌或原始 IP |
| `sys_operation_log` | 用户与时间索引 | 阶段0关键系统操作审计骨架 | 摘要不可包含敏感正文 |

所有适用主数据表使用 `created_by/created_at/updated_by/updated_at`；时间按 UTC，API 使用 ISO 8601。`sys_refresh_token`、登录与操作日志按安全证据语义保留，不随业务对象删除。
