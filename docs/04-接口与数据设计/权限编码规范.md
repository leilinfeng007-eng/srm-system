# 权限与菜单编码规范

- 权限格式：`domain:resource:action`。
- `domain` 与后端模块权限前缀一致；`resource` 使用小写 kebab-case。
- 首期 action：`view`、`create`、`update`、`delete`、`submit`、`approve`、`export`、`manage`。
- 一级菜单 code：`MENU_<DOMAIN>`；二级菜单 code 以同一前缀继续命名。
- `menuCode`、`route`、`componentKey`、`permission` 四元组来自 `frontend/module-manifest.json`，不得运行时猜测。
- 后端接口执行 RBAC；前端菜单隐藏不是安全边界。
- `SUPER_ADMIN` 获得全部已启用菜单/权限；`SKELETON_VIEWER` 仅获得清单中显式授权的只读骨架菜单。
- 阶段7预测与交付计划 `enabled=false`，不授权、不生成页面、不可直接访问。
