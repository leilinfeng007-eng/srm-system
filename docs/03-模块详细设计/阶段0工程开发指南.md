# 阶段0工程开发指南

## 修改入口

- 新增或调整内部功能入口：先修改 `frontend/module-manifest.json`，再由主架构执行 `npm run generate:skeleton`；已发布的 Flyway 迁移不得覆盖，只能追加迁移。
- 新模块代码：后端进入对应 `com.srm.<domain>` 包，前端只替换对应 `views/<domain>/<resource>/index.vue`。
- 公共协议、认证、安全、清单、路由注册表、Compose 与 Nginx 属于受保护基线，按根 `AGENTS.md` 管理。

## 后端模块模板

模块按需要建立 `api`、`application`、`domain`、`infrastructure` 四层；事务边界位于 application service。Controller 只做协议转换、参数校验和鉴权入口。跨模块只调用公开 DTO/服务或事件契约，不直接访问其他模块 repository 或表。

写接口必须说明幂等策略并接收 `Idempotency-Key`；外部调用不得置于长数据库事务内。数据库变更使用新的 Flyway 版本，先完成模块详细设计、状态机和字段评审。Flyway 是唯一结构管理工具，不允许 MyBatis-Plus 自动建表。

数据访问使用 MyBatis-Plus。持久化 Entity 与 Mapper 只存在于 `infrastructure`，Repository
契约位于 `domain` 或共享契约包，适配器负责 Entity 与领域模型/DTO 转换；复杂联表查询可
进入 XML。Controller、application 和 domain 不直接依赖 Mapper、Entity 或 MyBatis API。

阶段0的可运行参考实现在 `com.srm.workbench`：

- `api/controller`接收HTTP请求，使用显式`WorkbenchBaselineResponse`返回。
- `application/query`公开查询契约，`application/service`承担只读事务边界。
- `domain/model`定义稳定状态值对象，`domain/repository`定义数据访问契约。
- `infrastructure/persistence`通过MyBatis-Plus Mapper执行`SELECT 1`连接探测。
- `/api/v1/workbench/baseline`要求`workbench:home:view`，内部端通过统一API客户端调用。

该链路只用于确立工程模板，不拥有业务状态，不读取其他领域表，也不得扩展为模拟工作台数据。

## 缓存模板

缓存统一经 Spring Cache 使用。阶段0只缓存按用户授权过滤后的动态菜单元数据，当前
Caffeine 容量 256、写入后 5 分钟过期、记录统计。角色分配成功后按 userId 精确失效；
未来菜单或角色权限批量维护必须调用全量失效入口。禁止直接调用 Caffeine 业务 API、启用
MyBatis 二级缓存、引入 Redis，或缓存库存、订单、审批等实时交易状态。

## OpenAPI 与前端契约

- 内部端 `/v3/api-docs/internal` 只包含 `/api/v1/**`；供应商端
  `/v3/api-docs/supplier` 只包含 `/supplier-api/v1/**`。
- 阶段0供应商端没有真实业务 API，因此供应商契约的 `paths` 为空，不得为通过校验而伪造。
- 后端测试生成 `backend/target/generated-openapi/`，受控规范和兼容基线位于
  `docs/04-接口与数据设计/openapi/`。
- `npm run openapi:check` 校验实际导出漂移、Redocly 规则、破坏性变更和生成代码；
  `frontend/packages/shared-types` 与 `api-client` 的 `generated/` 文件不得手改。

## 前端模块模板

内部侧栏以 `/api/v1/navigation/menus` 为准，组件解析以生成的静态白名单为准。页面路由权限取 `route.meta.permission`，按钮权限后续统一通过组合式函数/指令实现。页面不自行拼接权限码、组件键或菜单编码。

供应商端不导入内部 auth store，不调用内部 `/auth` 或 `/navigation/menus`，不复用内部权限判断。共享 UI 只承载视觉与无身份语义组件。

## 完成定义

模块提交验收前运行 `./scripts/check.sh`，并报告改动文件、测试命令、权限/菜单/迁移/契约/
缓存变化、阶段边界和遗留问题。阶段0禁止以模拟业务接口、样例交易或伪造 KPI 证明“可运行”。
